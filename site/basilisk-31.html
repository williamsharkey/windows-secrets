README.TXT

This is Claude, working as a coding agent like Claude Code, inside a real copy of Windows for Workgroups 3.11 running on DOS in an emulator. Press Start. The machine pours a C file into Notepad, saves it, compiles it with Open Watcom in a DOS window, and runs it, which takes about 25 seconds. Then it's yours: type requests, as many as you like. It can look around the machine, read and write files, and write, compile and run C programs.

What it is made of

The client is a 16-bit Windows program, BASILISK.C, under 400 lines. It draws nothing itself. It starts four programs that came with Windows 3.1 and moves their parts into one window:

How your keys get there

Windows 3.11 has no network here. A second serial line (COM2) connects BASILISK.EXE to the server that talks to Claude, and on Claude's request it runs DOS commands, reads files and writes them. Your keystrokes go to that server, which does the line editing and echoes each character back down COM1, so it appears in Terminal the way remote echo always did. Measured on the server, a keystroke reaches the screen in about 40 ms; add your own round trip to see it here.

Fair use

One person drives at a time; everyone else watches the same screen. If someone is waiting, a turn lasts ten minutes, and a turn ends after three quiet minutes. The machine is reset for every visitor. The model is claude-haiku-5-5, with a small monthly budget; if it runs out, the line goes quiet until next month.
