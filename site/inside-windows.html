Inside Windows@ 0x99

Hidden keys, secret switches, test hooks and buried credits, found by reading the binaries of Windows 3.11 and Windows 7 instead of their windows.

This is the companion to Windows Secrets, which found hidden controls by resizing dialogs. Here a scanner (tools/codehunt.py) reads string tables, accelerator tables, version resources and the literals that code passes to registry, INI, compare, message, DDE and pipe APIs. Every card shows the file, the offset or resource, and the real bytes.

013.11accelerator · INI gateverified statically

Hearts: a Ctrl+Alt+Shift+F12 toggle that only works when WIN.INI says ZB=42

C:\WINDOWS\MSHEARTS.EXE · ACCELERATOR HEARTSACCEL → command 121 · handler seg1:0454
WIN.INI [Hearts] ZB=42thenCtrl+Alt+Shift+F12→toggles a drawing flag

The accelerator maps the chord (flags 0x9d) to command 121. No menu item has that ID: the menu runs 101–127 and skips 121. The handler calls GetProfileInt("Hearts", "ZB", 0), compares the result with 0x2a, and only then toggles word [si+0x12], invalidates the window and updates a menu check mark. The toggled word is passed to the card-drawing routine at seg1:3ca0 from at least four call sites.

It switches to drawing every hand face up, which matches the folklore "ZB cheat".

Add [Hearts] / ZB=42 to WIN.INI, start Hearts, press Ctrl+Alt+Shift+F12.

023.11key handler · INI gateverified statically

Minesweeper 3.1: three undocumented function keys and a boss key

C:\WINDOWS\WINMINE.EXE ("Minesweeper v3.0a") · WM_KEYDOWN handler seg1:063a · "XYZZY" at data seg2:0036
winmine.ini Sound=2+F4→toggle sound (SOUND.OPENSOUND …)
winmine.ini Menu=1|2F5→hide menu bar·F6→show it
Esc→WM_SYSCOMMAND SC_MINIMIZE (boss key)
XYZZYthenShift→xor [0x34], 0x14 (the known cheat)

Sound= is read with default 0, min 0, max 3; F4 does nothing below 2. The sound path calls SOUND.OPENSOUND, SETVOICEACCENT, STOPSOUND and CLOSESOUND, the Windows 3.x speaker-music driver. F5 and F6 call SetMenu(hwnd, NULL) or restore the saved menu, and need Menu=1 or 2 (default 0 disables them). The switch below dispatches on the key code by repeated subtraction, so each sub al is one key.

Put Menu=1 under [Minesweeper] in winmine.ini, then press F5 and F6.

033.117command-line switch · acceleratorverified staticallywindow style verified at runtime

Notepad's /.SETUP mode, spelled out one byte at a time in 3.11

NOTEPAD.EXE (3.11) seg2:00e1 · notepad.exe 6.1.7601.18917 (7) code 0x01002758, string at file 0x1b78 · ACCELERATOR SlipUpAcc
notepad /.SETUP file.txtEscorCtrl+D→Exit (cmd 28 in 3.11, 7 in Windows 7)

Notepad has a second accelerator table, SlipUpAcc, that normal runs never load. In 3.11 there is no /.SETUP string anywhere: the code compares the argument with '/' '.' 'S' 'E' 'T' 'U' 'P' one immediate at a time, then loads SlipUpAcc. String scanners cannot see a switch like this. In Windows 7 the command line is compared with L"/.SETUP"; a match sets a flag, loads SlipUpAcc, calls SetWindowLongW(GWL_STYLE, 0x00FD0000) (no minimize box), opens the named file read-only and changes WM_SYSCOMMAND handling.

The table also maps Ctrl+C and Ctrl+Z to Exit, but those entries come after Copy and Undo in the same table, so TranslateAccelerator never reaches them.

The window style was later checked live on Windows 7 (H7): /.SETUP gives an invisible, non-minimisable Notepad. Esc was not sent, so the exit keys are still static only.

notepad /.SETUP file.txt, then press Esc.

097test hook · registered messageverified statically

Power Options listens for a PowerCplTest window message

powercfg.cpl · RegisterWindowMessageW at 0x07b141bf · handler 0x07b139bd → 0x07b15e05

When the message arrives with wParam=1, the handler finds an item in the Advanced settings tree (control 0x451) and sends it TVM_ENSUREVISIBLE (0x1114) and TVM_EXPAND (0x1102, TVE_EXPAND). Another process can drive the dialog to a setting by posting one registered message. It is a test-automation hook in a shipping control panel.

dxdiag.exe · HKCU\Software\Microsoft\DirectX Diagnostic Tool opened at 0x01012a63
Never SkipAllow WHQL ChecksStress ScanStress Skip StageStress Page ChangeStress Save FileStress Cancel Gather… Freq

193.11encoded creditsverified statically

The Windows 3.1 credits, XOR 0x99, in SHELL.DLL

C:\WINDOWS\SYSTEM\SHELL.DLL · RCDATA 9999 (2,064 bytes) · BITMAP 9997, 9998

XOR-ing the RCDATA with 0x99 gives the whole roll for the well-known 3.1 About-box easter egg. It opens with "Dedicated to all the hard-working people of the Microsoft Windows 3.10 Team!", then Lead by/BRADSI, Development (KARLST, PHILBA, …), Program Management, Testing, Multimedia, OLE, WinHelp, Fonts, Beta, Marketing, Documentation, Graphic Artists, and Special Thanks/to billg/mikehal/steveb/t-bear. The easter egg itself is well known; the decoding here comes straight from the bytes. Run the decoder above.

In the stored bytes, each record starts with 00 and a one-byte running count (01, 02, 03 …), which XOR to 99 98, 99 9b, 99 9a. The decoder shows them as ‹01›, ‹02›.

Method and limits

The scanner uses only the Python standard library (Pillow is optional, for rendering icons). Disassembly was done with capstone: x86-32 for Windows 7 and 16-bit for 3.11, with Win16 imports resolved through the NE relocation tables. The excerpts on this page were re-extracted from the same files; addresses in the left column are virtual addresses (PE) or segment offsets (NE), and the second column is the file offset.

python3 tools/codehunt.py --mui w7/en-US --icons-dir icons  w7/System32  > codehunt-w7.jsonl
python3 tools/codehunt.py --icons-dir icons  wfw311/              > codehunt-w311.jsonl
  • Unreferenced-resource checks only catch direct immediates. Windows 7 regedit's "Binary Data" DIALOG 2021 looked orphaned, but it is loaded as DialogBoxParamW(…, 0x7e4 + (arg != 0), …) at 0x01017dcd. Card faces, toolbar strips and ribbon images are referenced as base+n.
  • Codename hits need context. OLE2CONV.DLL's "Chicago" and "Cairo" are Macintosh QuickDraw font names (next to "New York", "Geneva", "Los Angeles"), not the Windows 95/NT codenames.
  • API-argument records collect every string pushed shortly before a call, so neighbouring calls can bleed into one record.
  • Inline character compares, like 3.11 Notepad's /.SETUP, are invisible to any string-based scan.
