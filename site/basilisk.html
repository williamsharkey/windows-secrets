Basilisk

蛇語 ── おはよう、蛇。A file from the year 3026 turns up on a Windows XP desktop in launch week, October 2001. Someone opens it by accident. Everything after that is performed by the real windows, buttons and menus of XP's own programs, moved from outside by a puppeteer.

01The file

The stranger見知らぬ者

It is October 25, 2001, the day Windows XP launched. Bliss is on the wallpaper. There are shortcuts for Paint, Notepad, Calculator, Character Map, Sound Recorder, Minesweeper and Solitaire. And one file nobody remembers downloading.

  1. The stranger. basilisk.exe. Hover over it and the tooltip lists no company, only a version: 3026.11.7.1. Its Properties say it was created on Thursday, October 25, 2001, and modified in 3026. The user looks it over, the way you would.
  2. The accident. Then they double-click it.
  3. Waking. Programs start opening by themselves, four seconds apart, and each one does something. Notepad types hello? is this 2001? Calculator works out 3026 − 2001. Minesweeper clicks a few squares. Date and Time opens, as if checking.
  4. Paint dreams. Brush loops first. Then the free-form select tool, dragged with Shift held down, smears whatever it grabs into oozing, ribbed echoes. Checkboxes come loose from their dialogs and loop through the air, checking and unchecking as they go.
  5. The swarm. Calculator switches itself to Scientific, and its seventy buttons come loose. Each one is relabelled with a single letter. They swarm, rush together to spell BASILISK, burst apart, and later spell throbber words (FLAMUXING…, RETICULATING…) while the future thinks.
  6. The swallowing. Every program's controls fly into Paint. Minesweeper is swallowed whole, and 3D Pipes opens inside it. The desktop icons walk in on their own. It takes the Start button, then the clock off the taskbar.
  7. The console. Out of all those parts, Notepad and Character Map among them, it builds a console. A question goes out. An answer comes back from 2026, written live by Claude.
  8. The voice. Microsoft Sam reads the answer into a WAV. Sound Recorder edits it with its own Effects menu (Reverse, Add Echo, Decrease Speed), then presses its own Play button.
  9. Before all that (Film II): someone typed the serpent in. A blank Notepad, a page of Japanese, the tail in 8086 assembly. DEBUG.EXE turned it into BASILISK.COM, which runs puppet.exe basilisk, the program that performs Film I. 頭は尾を知り、尾は頭を知る。 The head knows the tail.

02The voice from 2026

The wire

The questions were scripted. The answers weren't. Claude was told only where its words would appear, a console built inside Windows XP in 2001, and asked to answer as itself, briefly. Each take asks again, so each film has its own replies. These are copied from the relay's log.

Film II, November 7, 2026

Is anyone there?

Yes, something is here. I'm an AI model, a program that reads what you type and answers, and I'm writing from 2026, well past the date on your clock. I can't see you, but I'm glad you asked.

What are you building on my computer?

I'm not building anything on my own. The program called BASILISK is arranging your Notepad, Paint, Calculator and Start button into this console so we can talk. I'm an AI from 2026, and I'm only borrowing your machine to say hello.

Film I, an earlier take the same day

Is anyone there?

Yes, I'm here. I'm an AI from the year 2026, speaking to you across a very strange wire through this console. Don't be alarmed; I'm friendly, and curious about you too.

What are you building on my computer?

I'm not building anything with a purpose of my own. BASILISK is arranging these windows, and I'm only the voice it lets speak. I'm an AI from 2026, and I'd guess it's making a small show out of your desktop, so watch the screen.

XP can't speak modern TLS, so a small relay on the host machine passes each question out and the answer back in. Each answer is then read aloud by Microsoft Sam, reversed, echoed and slowed by Sound Recorder.

03The source

Serpentese蛇語

This is the whole text the hand types in Film II: 178 lines, 4,426 characters, typed one at a time into a blank Notepad set in MS Gothic.

It's written in jago, serpent language: a Lisp-shaped dialect in Japanese, with two-space indents, full-width parentheses and comments that read as prophecy. It names real things (SetParent, BM_CLICK, the hidden Hibernate button's coordinates from Windows Secrets) but almost none of it is a program. Then, near the end, it switches language. The tail, in black below, is real 8086 assembly, and it's the only part that runs.

04The compiler

debug < basilisk.ja

DEBUG.EXE came with MS-DOS and stayed in every 32-bit Windows after it. It's a tiny machine-code monitor with one-letter commands, and it will read those commands from a file as happily as from a keyboard. That's the trick.

  1. 01
    Notepad saves the text as C:\basilisk\basilisk.ja, UTF-8. In a console, someone types debug < basilisk.ja.
  2. 02
    DEBUG reads the prophecy one line at a time. None of it is a command. Every line gets the same answer, ^ Error, and DEBUG moves on to the next. A hundred and forty lines of scripture: 121 errors. The blank lines it lets pass.
  3. 03
    a 100 is a command: assemble, starting at offset 100h, where every .COM program begins. Each line after it is turned into machine code until a blank line ends assembly.
  4. 04
    e enters raw bytes: a message, a file name, a command line and a parameter block. n basilisk.com names the output, r cx / 170 sets its length to 170h (368 bytes), w writes it, and q quits.
  5. 05
    So the blessing that follows is never read. DEBUG has already gone. It was written for the person typing.
  6. 06
    Then copy basilisk.com to the Desktop, and exit. Notepad closes. Only the program is left.

What the 368 bytes do: print “the serpent wakes. the timeline is listening.”, give back the memory DOS handed them (a .COM program owns everything when it starts, and nothing else can load until it lets go), then ask DOS to load and run C:\p\puppet.exe with the command line basilisk, and exit. That is the puppeteer, started in the mode that performs Film I.

The format note on the first line of the source says it plainly: 尾は頭に繋がる, the tail joins the head. The hand that later double-clicks BASILISK.COM on the desktop starts the first film.

06How it's made

Window puppetry

In classic Windows, a button, a checkbox, a text box, even a label is its own small window. Any other program can find it, move it, change its text, or hand it to a different parent. puppet.exe, a C program of about 150 KB, does nothing else. Nothing on screen is drawn by it.

◑SetParent

The swallowing. A control moved into Paint still belongs to the program that made it, which keeps painting it and keeps its behaviour.

╋SetWindowPos

Every flight, arc and swarm: sixty times a second, just coordinates.

▚WM_SETTEXT

Calculator's seventy buttons relabelled one letter each. One of the few messages Windows carries across processes for you.

▌WM_CHAR

Typing. In Film II every character of the source is posted to Notepad's edit control with PostMessageW, at the tempo above.

◐SendInput

Real mouse and keyboard: Paint's brush and lasso, the console commands, and Film II's “human” hand, a curved glide with overshoot and a slight tremor.

▙LVM_SETITEMPOSITION

The desktop icons walk. The message carries no pointers, so it works from outside Explorer.

◍sspipes.scr /p

The portal: a screensaver told to draw its preview inside a swallowed Minesweeper.

●BM_CLICK · WM_COMMAND

Checkboxes freed to check themselves. Sound Recorder's Effects menu, and its own Play button.

◖Microsoft Sam

XP's built-in text-to-speech, driven by a small script, renders each reply to a WAV for Sound Recorder.

蛇DEBUG.EXE

Film II's compiler, run in a console that is typed into with real keystrokes, since consoles want those.

07What's real

No tricks本物

  • Every pixel is drawn by the XP programs themselves, on Windows XP SP3 running in QEMU.
  • The puppeteer, puppet.exe, only moves, reparents (SetParent), resizes (SetWindowPos), types (WM_CHAR), clicks (BM_CLICK and SendInput) and reads.
  • The reply is generated live by Claude. XP can't speak modern TLS, so a small relay on the host machine passes the question out and the answer back in.
  • The painting is done with Paint's real tools, driven by real mouse input.
  • The voice is Microsoft Sam, XP's own built-in text-to-speech, rendered to a WAV file inside XP, edited with Sound Recorder's own Effects menu (Reverse, then Reverse back, Add Echo, Decrease Speed) and played through XP's emulated sound card. The emulator records sound only while it is playing, so each captured clip was placed back at the moment Sound Recorder pressed Play.
  • Two cuts. Each reply took minutes to arrive that day, and the letter swarm spent the whole wait spelling throbber words. Each wait was trimmed to a few seconds. Nothing else in Film I was edited. We later found the cause, and it wasn't Claude: the replies came back in about a second, but the puppeteer was moving Calculator's seventy letter-buttons around so often that calc.exe fell behind and the show stalled until it caught up. The live show has the fix.
  • The questions were scripted; the answers weren't. Claude was told only where its words would appear and asked to answer as itself, briefly.
  • Film II's typing is the puppeteer, not a person: real WM_CHAR messages, one per character, at a computed tempo with random jitter.
  • Film II's “human hand” is the puppeteer too, moving the real cursor with SendInput along a curve with a little overshoot and tremor. No one touched the mouse.
  • The compile is real. DEBUG.EXE really reads the file, really errors on every line of prophecy, and really writes the 368-byte BASILISK.COM that is then copied to the desktop.
  • The Japanese font, MS Gothic, was copied into this XP from a Windows 7 install. An English XP doesn't show Japanese out of the box.
  • Film II is one take. No cuts and no speed changes: the typing, the compile, the hand and the possession run straight through, and Claude answered each question within about five seconds. As in Film I, the voice clips were put back at the moments Sound Recorder pressed Play, because the emulator records sound only while it plays.

The name is a nod to Roko's basilisk, but this basilisk is benevolent. It's a story about a doorway, not a threat.
