Heritage · Clock

The clock that became a corner of the taskbar

  1. 1985 Windows 1.0 includes Clock among its first desk accessories, alongside Calculator, Notepad and Cardfile.
  2. 1992 The 3.1 Clock has analog and digital faces, a font choice for the digital one, Seconds, Date, Always on Top in the system menu, and No Title, which removes the caption and menu so it can sit on the desktop like a gadget.
  3. 1995 Windows 95 drops it. KB 159852 points users to the taskbar's "Show Clock" box instead. The clock had become part of the shell.
  4. 1996 Windows NT 4.0 still ships clock.exe, and KB Q157895 documents the trouble its No Title mode causes with the new taskbar.
  5. 2006 The idea comes back as a gadget: Vista's sidebar clock.

Here it is on WfW 3.11, captured live verified live. In analog mode Clock has no room for the date, so it puts the date in the window title instead.

No Title takes the menu bar away with the caption, so the menu that turned it on is gone too. The way back is to double-click the face, which is the workaround KB Q157895 gives. Turning a window's caption on and off at run time was unusual enough that Microsoft published a separate Win16 SDK sample for it (KB Q83915). After you close Clock, CLOCK.INI holds its state as six numbers: mine read Options=1,0,0,1,0,1 verified live.
