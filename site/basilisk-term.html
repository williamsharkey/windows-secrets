BASILISK III

A working Claude Code client, assembled from Windows XP's own parts. Notepad keeps the transcript, Notepad's Find box takes your words, Date and Time keeps the clock, Calculator keeps the bill. It runs on a real XP machine; Claude works in it with real tools. Press start, wait for it to build itself, then type.

How to drive

  • Click the screen, then type. Enter sends, Esc stops Claude.
  • ↑ ↓ recall what you typed. PgUp PgDn or the mouse wheel scroll back.
  • Paste works (Ctrl+V). /help, /clear, /model sonnet, /cost.
  • One person drives at a time; everyone else watches live. If someone is waiting you get ten minutes, otherwise as long as you keep typing.

Things to try

  • What is this machine? How much memory does it have?
  • Write a C program that draws a spiral in a window, compile it with tcc and run it.
  • Make a JScript that prints the first 30 primes.
  • What are the ten biggest files in C:\WINDOWS?

What it's made of

Each session starts from a clean desktop. A blank Notepad receives basilisk.c, it is saved to the desktop and compiled there by the Tiny C Compiler, and the program takes Notepad, Notepad's Find dialog, the Date and Time page and Calculator's display, and puts them together. Every part is still drawn by the program that made it. Claude (Haiku 5.5 by default) runs the conversation on a server; its four tools (run a command, read, write and edit a file) run inside XP. The machine has no internet and is reset after every session. Source.
