BASILISK 3.11 in your browser

Windows for Workgroups 3.11 boots inside this page. It pours a C file into Notepad, compiles it with Open Watcom, and the program it builds turns Notepad, Clock, Cardfile and Calculator into a Claude Code client. Everything you see and everything you type stays on your machine; only your words for Claude, and what Claude asks this Windows to do, cross the network.

Windows for Workgroups 3.11 is about 20 MB. It runs here, in your browser.
Not started.

How to use it

  • Click the screen, then type: the letters go into Notepad's Find box, as real keystrokes.
  • Enter sends, Esc stops Claude, ↑ ↓ recall, PgUp PgDn or the wheel scroll.
  • /help, /clear, /cost. Reloading the page starts Windows afresh.
  • Try: write a C program that prints a multiplication table, compile it and run it.

What happens

The page loads DOSBox-X compiled to WebAssembly (js-dos) and boots Windows for Workgroups 3.11 from a disk image. A small 16-bit program pours BASILISK.C into Notepad, saves it, and runs Open Watcom's compiler in a DOS window, all inside your browser, in about 20 seconds. The program it builds takes Notepad's edit for the transcript, Notepad's own Find dialog for the input bar, Clock, a Cardfile card for the status, and Calculator's display for the bill. Windows and the page pass notes through two files on its C: drive.

What goes over the network

When you press Enter, your sentence goes to a small server that talks to Claude (Haiku 5.5). Claude's reply streams back into Notepad; when Claude wants to run a DOS command or read or write a file, the request comes to this page and BASILISK.EXE does it inside your Windows. Nothing else leaves the page. The other version of this, BASILISK 3.11, runs on a server and streams its screen instead.
