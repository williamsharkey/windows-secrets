BASILISK 3.11 in your browser

Windows for Workgroups 3.11 runs inside this page, in DOSBox Pure compiled to WebAssembly, resumed in about a second from the moment its Claude Code suite finished assembling: a 16-bit program that turns Notepad, Cardfile, Clock, Calculator, File Manager and Control Panel into a Claude Code client, with five Cardfile cards for tabs. Everything you see and everything you type stays on your machine; only your words for Claude, and what Claude asks this Windows to do, cross the network.

Windows for Workgroups 3.11 is about 20 MB. It runs here, in your browser.

How to use it

  • Click the screen, then type: the letters go into Notepad's Find box, as real keystrokes. The mouse works too: Windows' own pointer follows yours.
  • Enter sends, Esc stops Claude, ↑ ↓ recall, PgUp PgDn or the wheel scroll.
  • Alt+1…5, or a click on a card's header, changes card. On Files, Ins puts the selected file into your message as @NAME.
  • /help, /clear, /compact, /cost. Reloading the page starts Windows afresh.
  • Try: plan and write a C program that prints a multiplication table, compile it and run it.

The five cards

  • 1 Chat: Notepad's edit is the transcript; Notepad's own Find dialog, shorn of its options, is the input bar (Find Next is Send, Cancel is Stop).
  • 2 Plan: a second Notepad holds Claude's to-do list, which Claude keeps with a todo_write tool. Before a command or a file write, Windows asks you in a real message box: Yes runs it once, No allows that command from now on, Cancel refuses.
  • 3 Files: File Manager's directory window on C:\B3\WORK. A CLAUDE.MD there is read before each turn, as standing instructions.
  • 4 Usage: gauges drawn the way 3.1 Setup draws its progress bar: context used, your share of today's cap, everyone's share of the month's.
  • 5 Settings: Control Panel's Mouse dialog, relabelled. Its sliders set effort and answer length; its check boxes, asking before commands and Claude Sonnet 5.5 instead of Haiku 5.5.

What happens

The page loads DOSBox Pure, compiled to WebAssembly (the same engine as BASILISK 16's "Try it online", running in a worker), with the C: drive of Windows for Workgroups 3.11 and a snapshot of the machine. The snapshot was taken just after BASILISK.EXE (built by Open Watcom from BASILISK.C and PARTS.C, which are on C: in \B3) assembled the suite, one part at a time: Notepad filled the screen, Find became the input bar, Clock and Calculator's display joined the right-hand column, Cardfile opened five cards and gave them up, and Notepad, File Manager and Control Panel went behind their cards. Every Windows pixel is shown as a whole number of screen pixels.

What goes over the network

When you press Enter, your sentence goes to a small server that talks to Claude (Haiku 5.5 unless you pick Sonnet 5.5 on the Settings card). Claude's reply streams back into Notepad; when Claude wants to run a DOS command or read or write a file, the request comes to this page and BASILISK.EXE does it inside your Windows. Nothing else leaves the page. Windows and the page pass notes through the emulated BASILISK 16 sound card's message ports; your keys go to the emulated keyboard, and your pointer to the emulated mouse (BASILISK.EXE places Windows' pointer). The other version of this, BASILISK 3.11, runs on a server and streams its screen instead.
